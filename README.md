# GDAL_prac

Research and practice workspace for GDAL (Geospatial Data Abstraction Library).

Scope of the work kept here:

- Capability survey of GDAL: architecture, driver ecosystem, CLI surface, subsystems, bindings, and distribution options.
- Security analysis comparing the GDAL Python bindings (`osgeo`) against the command-line utilities, with a focus on reducing exposure when processing untrusted geospatial data.
- Hands-on GDAL experiments.
